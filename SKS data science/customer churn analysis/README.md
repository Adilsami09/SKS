# Telco Customer Churn Analysis

This project analyzes the telecom customer churn dataset and completes the first four data science tasks:

1. Business understanding and project goal
2. Data inspection and cleaning
3. Exploratory data analysis (EDA)
4. Data preprocessing and model-ready preparation

## Dataset

- File: `Telco_Customer_Churn_Dataset  (3).csv`
- Target variable: `Churn`

## Run the project

```bash
python churn_project.py
```

## Output

- Console summary of each task
- Charts saved in the `outputs/` folder
- A prepared, model-ready dataset for the next step of the project
